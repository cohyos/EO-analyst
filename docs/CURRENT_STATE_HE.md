- Windows native: PostgreSQL, ntfy, שרת FastAPI ו־orchestrator, ללא צורך ב־Docker.
- הממשק הוא React/TypeScript ונבנה ל־`web/dist`; האפליקציה זמינה ב־http://127.0.0.1:8765/.
- חיפוש באמצעות ddgs; המפתח `searxng` בנתוני הסטטוס נשמר לתאימות.
- גרף בטבלאות SQL; וקטורים במערכי PostgreSQL וחישוב numpy, ללא דרישת AGE/pgvector.
- תצורת LLM תומכת בספקי ענן וב־Ollama. ההתקנה מוגדרת לענן. זמינות ועלות תלויות בספק.
- מודלי השיחה המקומיים מושהים; `eo models pause-local --allow-embed` מתיר עיבוד
  וקטורי בכפוף לבדיקות המשאבים. `eo models pause-local` מחזיר השהיה מלאה. סינון
  אבטחה על CPU נשאר פעיל. קריאות השפה משתמשות בספקי הענן המוגדרים.

## הפעלה ומשאבים

מתיקיית הפרויקט: `.\.venv\Scripts\eo.exe native start`, ולבדיקת מצב: `native status`.
המפקח מנהל את תהליכי האפליקציה; PostgreSQL נשאר פעיל בעת עצירה רגילה. סגירה כוללת
את צאצאי התהליך. בדיקת חיות זולה: `GET /api/health`; מצב מפורט: `GET /api/status`.
בדיקות השירותים נשמרות במטמון ל־15 שניות. חיווי חיפוש ddgs בודק התקנה, ולא מבצע
שאילתת חיפוש בכל עדכון; בדיקת ספק מלאה נשארת ב־pre-flight.

כאשר הסקה מקומית מותרת, נעילה משותפת בין תהליכי EO נמשכת לאורך כל הקריאה.
מצב התחשבות ב־GPU חל גם בלילה ובצ׳אט. מודלים בשרת Ollama משותף אינם מפונים
אוטומטית. אלה אינן מגבלות CPU/RAM כלל־מערכתיות או זיהוי אימון אוטומטי; לפני אימון
ביישום אחר יש להשאיר את ההשהיה פעילה ולסיים קריאות מקומיות שכבר התחילו.

## עבודות ודוחות

ה־worker מחדש תוקף עבודות בבעלותו מדי 30 שניות, בנפרד מהתקדמות המחקר. תוצאות
והתקדמות נכתבות עם בדיקת בעלות. תקציב כל שלב מועבר לבדיקות עצירה בין פריטים,
לחיפוש ולקריאות מודלים. קריאת CLI שחורגת מהזמן מסיימת את עץ התהליכים שלה.
עבודה שכבר נשמרה נשארת במסד; שלב שפג זמנו מסומן כחלקי, ונשמר תקציב לדוח.

העצירה שיתופית: קוד חישוב ללא נקודות בדיקה עשוי לסיים את יחידת העבודה הנוכחית,
ו־timeout של בקשת HTTP תלוי גם בהתנהגות ספריית הרשת. אין הרצת שלב ברקע אחרי
החזרת תוצאת timeout מלאכותית.

מסך הבוקר מציג תאריך ומצב הריצה, מסמן שלב שנקטע ומזהיר על דוח בן יותר מ־24 שעות.
חזרות מדויקות באינדיקטורים מצומצמות בעת הפקת דוחות חדשים, תוך שמירת הבדלים
בסטטוס ובראיות; נתונים ודוחות היסטוריים נשמרים.

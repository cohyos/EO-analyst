## מטרת המערכת והמבנה בפועל

EO-Analyst הוא כלי מחקר OSINT לתעשיית האלקטרואופטיקה הביטחונית, EO/IR וראייה
ממוחשבת. הוא אוסף פריטים, מסווג ומתעדף אותם, מבצע חקירות עומק ומפיק דוחות בעברית
עם סימוכין. קוד האפליקציה מפעיל הסקה במודלים; הוא אינו מנגנון אימון מודלים.

- `agent/eoa/`: שרת Python, CLI, תזמון, מחקר, סינון אבטחה, זיכרון ויצירת דוחות.
- `web/src/`: React 19, TypeScript, React Query, Zustand, RTL ושפות; גרפים באמצעות Cytoscape.
- `config/`: מקורות, רשימות מעקב, טקסונומיה, קווי מוצר, אוצר מפרטים, מודלים ותקציבי עבודה.
- `db/migrations/`: מסד PostgreSQL והרחבות הסכמה עד מיגרציה 0032.
- `tests/`, `web/src/**/*.test.*`, `e2e/`, `evals/`: בדיקות שרת, ממשק, תרחישי דפדפן והערכת תוכן.

ההתקנה הפעילה היא Windows native: PostgreSQL, ntfy, orchestrator ו־FastAPI מנוהלים
באמצעות `scripts/native/eoa-supervisor.ps1`. השרת מגיש גם את `web/dist` בפורט 8765.
Ollama הוא שירות נפרד. `config/config.yaml` מוגדר למצב ענן עם שרשראות גיבוי למקומי;
החיפוש הוא `ddgs`. הגרף ממומש בטבלאות SQL והווקטורים במערכי PostgreSQL עם חישוב numpy.
תיאורי Docker/AGE/pgvector והצהרות "הכול מקומי" במסמכים ישנים אינם משקפים את ההתקנה הזו.

## זרימת העבודה

המחזור היומי ב־`agent/eoa/orchestrator/jobs.py`:

קליטה → embeddings והסרת כפילויות → סיווג → קישור כפילויות בין שפות → תעדוף →
חקירות עומק → ניתוח → אישוש → מכרזים → השלמת עיבוד פריטים שנוספו במכרזים →
דוח → יצוא וגיבוי → התראה.

עבודות נשמרות בטבלת `jobs`, נלקחות באמצעות `FOR UPDATE SKIP LOCKED` וכוללות בעלות
וחלון תוקף. לממשק יש REST, חיבורי WebSocket לסטטוס ולחקירות, ו־SSE לצ׳אט.
מסלולים נוספים מטפלים בפטנטים, כנסים, מטע״דים, פיתוח עסקי וקווי מוצר.

סקירת מוצר משלבת קורפוס קיים, דפי יצרן ודפי נתונים, מחקר לפי נושאים, חילוץ מפרט
ועסקאות, שימור עובדות מסקירות קודמות, סימון פערים והשוואת גרסאות. ההפרדה בין עובדה,
טענת יצרן ואומדן אנליטי היא חלק חשוב ממודל הנתונים ומהדוחות.

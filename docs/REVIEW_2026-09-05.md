## ג. Docker לעומת התקנה מקומית (U14)

**למה Docker:** (1) בידוד רשת של סוכן ה-LLM מהאינטרנט (רשת ללא יציאה + DNS מנוטרל), שהיא דרישת האבטחה המרכזית; ב-Windows מקומי זה דורש חוקי Firewall פר-תהליך ושבירים. (2) PostgreSQL 17 עם Apache AGE ו-pgvector: ל-AGE אין בנייה רשמית ל-Windows. (3) SearXNG ו-ntfy הם שירותי Linux. (4) שחזור/העברה: `docker compose up` משחזר את כל הסביבה.

**מה כבר מקומי:** Ollama (GPU) רץ על Windows, לא בקונטיינר.

**אפשרות היברידית (מומלצת אם רוצים פחות Docker):** להשאיר בקונטיינרים רק את התשתית (postgres, searxng, ntfy) ולהריץ את agent ו-web ישירות על Windows (Python 3.12 + Node). יתרונות: דיבוג קל, בנייה מחדש מיידית, אין VHDX שתופח. עלות: אובדן בידוד הרשת של הסוכן (יידרש Firewall), והרצה כ-Windows Service במקום restart policy.

**מעבר מלא ללא Docker:** אפשרי רק בהחלפת רכיבים: AGE → טבלת קשרים ב-SQL (אובדן Cypher), SearXNG → WSL או חיפוש ישיר במנועים (CAPTCHA), ntfy → בינארי Windows (קיים). הערכה: 2–3 ימי עבודה + ירידה ברמת הבידוד. לא מומלץ בשלב זה.
